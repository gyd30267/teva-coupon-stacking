## The stacking rules that decide whether your code works

This is where most Teva coupon searches go wrong, because these rules only show up in checkout fine print, not on the coupon pages:

1. **One code per transaction.** Teva's checkout rules, as documented by deal testers, state: "Only one promotional code or coupon can be applied per transaction, and discount codes cannot be stacked with automatic cart promotions or bundle pricing." If you enter multiple codes, only the most recently applied valid one counts.
2. **Codes don't cover everything.** Promo codes don't apply to high-end designer collabs, limited editions, and final-sale clearance items.
3. **The email sign-up code is full-price only.** That 10% first-order code is meant for full-price purchases. If the style you want is already in the Sale section — say, Original Universal sandals at $38.99 instead of $65 — the Sale markdown wins. Doing the math: 40% off beats 10% off every time.
4. **No rain checks on price drops.** Teva "does not offer retroactive price adjustments or partial refunds if an item you previously purchased goes on sale or drops in price later." Your only move is to return within the 30-day window and reorder at the new price — though as you'll see below, a return can cost you your cashback, so factor that in before you play this game.

Points 3 and 4 are the two details almost no coupon roundup explains, and they change what you should actually do: skip the code for anything already marked down, and if you buy something at full price, keep an eye on it for the next month because your refund route is a return, not a price-match.

## The fine print worth knowing before you order

Free shipping is straightforward: **orders of $50+ ship free via standard ground within the contiguous US**, no code needed. Standard delivery runs 3–10 business days.
